# 文本分析器

先在 [main.cpp](E:/theCPP/learning_plan_20260914/projects/cpp/03_text_analyzer/main.cpp) 完成内存版本，后续课程继续添加文件、参数和多文件处理。不要一开始就拆目录；split_template只供10/10课程迁移自己的代码。

阶段顺序：9/30 map/set计数与查询 → 10/4排序和过滤报告 → 10/5原始文本分词 → 10/6文件输入输出 → 10/7命令行参数与错误 → 10/10拆文件与测试 → 10/11完整程序 → 10/12堆TopK对比 → 10/17批处理 → 10/18交付。

先固定规格：词是连续ASCII英文字母，小写作为统计键；数字、标点、其他字节视为分隔。停用词在计数前过滤。按次数降序，同频按小写单词升序。K=0没有榜单记录，K超过不同词数量时输出全部。不强求本月实现中文分词。

10/11再增加原拼写显示：同一个小写键保存第一次出现的原拼写；排序仍按小写键。多文件版按命令行文件顺序判断首次出现。每文件摘要与总词频分开，打不开的文件留错误记录，不当成空文件成功。

| 输入 | 预期 |
|---|---|
| 程序中的6词，停用词and | blue:2、red:2、green:1；有效总词数5 |
| basic.txt，停用词and | 同上；保留原拼写阶段显示BLUE:2、Red:2、green:1 |
| basic.txt + second.txt，停用词and | blue:4、red:3、green:2；有效总词数9 |
| basic.txt的Top2 / Top0 / Top99 | blue和red / 空榜单 / 全部3个词 |
| punctuation.txt或空字符串 | 0个有效词，空榜单 |
| 停用词包括所有出现的词 | 0个有效词，空榜单 |
| 查询不存在的yellow | 未找到，map大小不变 |
| 缺文件 / 空文件 | 前者是读取失败，后者是成功但无数据 |
| K为abc、-1、3x | 参数错误；不能只接受合法前缀3 |
| 基本样例仅保留长度4的词 | blue:2（red长3、green长5） |

建议最终调用形式：`app.exe --top 3 samples/basic.txt`。多文件阶段允许路径列表；具体参数处理你自己设计。报告路径与输入路径保持不同。
