# 网格机器人

从 [main.cpp](E:/theCPP/learning_plan_20260914/projects/cpp/02_robot/main.cpp) 的类开始，连续几课扩展同一个程序。函数体由你补；每阶段完成后再增加下一阶段的数据，不预先搭庞大结构。

|---|---|---|

| 9/27 快照历史 | 保留原状态；撤销一步、重放、只执行N条命令 | 撤销恢复最近一次成功动作之前的完整状态；空历史不崩溃；重放从同一起点结果相同 |

基础地图位于maps目录。坐标从0开始，向下为row增加，向右为col增加，S/E均可走。

初始地图建议契约：只接受矩形的`. # S E`字符地图，必须恰好一个起点和终点。命令撞墙或出界时保持状态并继续下一条；未知命令报告位置并跳过。只记录成功改变状态的动作；转向也算一个动作。重放基于保留的命令串，不依赖已经被弹空的撤销栈。

先用vector保存历史。到栈队列课程才改实现，这样能比较两种表示；不要同时维护两套不断互相同步的历史。

提示：转向先手画N/E/S/W顺序；移动先算候选位置再判断地图；撤销要保存方向与坐标；BFS先算最短距离，再记录前驱恢复路线。main保持演示入口，测试用固定命令串，不依赖反复手动敲键盘。
